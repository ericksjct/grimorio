## Premissas do planner (explícitas)

- **A-10:** colisão de slug é comparada em minúsculas (`slugKey`), a mesma normalização do
  índice `byName` de `pack-manager.jsx`. Um homebrew com `name: "Fireball"` colide com o
  reservado `fireball` — leitura mais estrita do D-08 ("slug é identidade única").
- **A-11:** ao renomear uma magia sem `displayName`, o nome antigo é copiado para
  `displayName` antes de trocar `name`, para o título visível não virar o slug novo (a
  renomeação muda a identidade, não o nome que o usuário lê).
- **A-12:** se `srd-reserved-slugs.json` não puder ser lido (offline sem cache, `file://`),
  o import falha fechado com `packErr.unknown` — sem a lista não dá para garantir o D-09.
  O arquivo é pré-cacheado pelo SW (08-06).
- **A-13:** `rename.errorDuplicate` cobre também "igual à nova de outra linha" e "igual a
  outro slug do mesmo pack" — a checagem é contra um único conjunto de slugs ocupados.

## Interface produzida (consumida pelo 08-05)

- `window.packImport.detectSlugConflicts(targets, owners)` — `targets`: `[{ name,
  displayName, oldKey }]`; `owners`: `Map<slugKey, [{ label, name }]>` → `[{ slug, name,
  oldKey, existing: [{ label, name }] }]`
- `window.packImport.slugOwnersOf(versionKeys)` → `Promise<Map<slugKey, [{ label, name }]>>`
  (magias adaptadas via `window.loadSpellVersion`, rótulo `labelEn` da versão)
- `window.packImport.loadReservedSlugs()` → `Promise<{ packs, slugs, owners: Map, keys: Set }>`
- `window.packImport.suggestSlug(slug, packSource, takenKeys)`,
  `validateSlugRename(value, reservedKeys, takenKeys)`, `applySlugRenames(spells, renames)`, `slugKey(s)`
- `window.renameInstalledPackSlugs(packId, renames: Map<nomeAntigo, nomeNovo>)` → Promise
- `window.renameImpact(oldKeys: Set, stillResolves: (key) => boolean)` → número
- `<window.PackRenameDialog lang dark theme open rows reservedKeys takenKeys impact onCancel onSubmit />`
  — `rows`: `[{ packId, slug, name, oldKey, existing }]`; `onSubmit(list)` recebe
  `[{ packId, slug, newSlug }]` e pode ser async (o diálogo mostra `rename.submitting`)
