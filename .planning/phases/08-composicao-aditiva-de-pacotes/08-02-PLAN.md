## Premissas do planner (explícitas)

- **A-05:** o UI-SPEC propõe `rename.impactWarning` como chave única com `{nounSpell}`, mas
  o texto PT fica agramatical com n = 1 ("afeta 1 magia preparadas ... que apontam"). O todo
  dobrado manda corrigir o plural das contagens novas → a chave vira o par
  `rename.impactWarning.one`/`.other` (mecanismo `plural(n)` de `noun.spell.*`; precedente
  de frase em `migration.orphansOne/Many`), cada variante com o texto do UI-SPEC.
- **A-06:** o estado "enviando" do prompt (UI-SPEC, linha loading do E2) precisa de uma
  string não listada: `rename.submitting`.
- **A-07:** variáveis de template em inglês (`{author}`, `{version}`, `{lang}`,
  `{edition}`, `{n}`, `{nounSpell}`); `{edition}` recebe `' · 2024'` ou `''` do chamador,
  para uma chave só cobrir com e sem edição (UI-SPEC `menu.cardMeta`).
- **A-08:** o teto de 200 KB do UI-SPEC é medido no comprimento da string do `data:` URI
  (204800 caracteres), não em bytes decodificados.
- **A-09:** os SRD embutidos NÃO ganham `meta.image` nesta fase — o D-17 diz que "podem"
  ter arte própria (permissão, não mandato) e não há arte licenciada no repo; eles usam o
  mesmo marcador de cor derivada (08-05).
