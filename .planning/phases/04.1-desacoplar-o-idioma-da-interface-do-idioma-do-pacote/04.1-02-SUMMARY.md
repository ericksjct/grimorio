# Phase 04.1 Plan 02: HifiLangToggle rewrite and dual mount Summary

**`HifiLangToggle` is now a 2-state, always-enabled interface-language switch (mirroring `HifiThemeToggle`'s shape) that writes only `window.__setUiLang`, mounted in both desktop footer and mobile drawer, with `VersionSelector` now speaking the interface language instead of the pack's.**

## Performance

- **Duration:** ~20 min
- **Tasks:** 3/3 completed
- **Files modified:** 3 (1 created, 2 modified)

## Accomplishments
- `HifiLangToggle` fully rewritten (`v10-hifi.jsx`): signature is now `{ uiLang = 'ptbr', style }`, no `versions`/`versionKey`/`onSwitch`; each button calls `window.__setUiLang('ptbr'|'en')` directly and is always clickable, with `lang="pt-br"`/`lang="en"` attributes added (D-13, WCAG 3.1.2) and the 🇧🇷/🇺🇸 flags kept (D-14)
- `hifiSiblingVersion` untouched and still declared - only `useEditionCompare` calls it now, killing the fixture behind the fase's origin bug (`versions.find(v => v.lang === 'ptbr')` returning `undefined` once no pack declares `lang: 'ptbr'`)
- `const uiLang = lang;` alias added at the top of both `HifiDesktop` and `HifiMobile`, with a one-line comment distinguishing `uiLang` (interface) from `versionLang` (pack)
- Desktop footer mount reduced to `<HifiLangToggle uiLang={uiLang}/>`; mobile drawer gained a new `<HifiLangToggle uiLang={uiLang}/>` next to `HifiThemeToggle` (D-10), and the now-false comment justifying its prior absence was deleted
- `window.VersionSelector` mount now receives `lang={uiLang}` instead of `lang={versionLang}` (D-02) - its own chrome (`version.switch`/`version.label`/`version.labelMobile`) now follows the interface language
- New `scripts/check-ui-lang-toggle.tests.ps1`: proves the toggle's signature, both `window.__setUiLang` calls, both `lang` attributes, both flags, zero calls to `hifiSiblingVersion`/`versions.find` inside the toggle (region-scoped), exactly 2 mounts with no `onSwitch`, both `uiLang` aliases, and `VersionSelector`'s `lang={uiLang}` wiring - confirmed red against the pre-plan `v10-hifi.jsx` (materialized via `git show 6c156e8:v10-hifi.jsx`, restored via `git checkout HEAD -- v10-hifi.jsx`)
