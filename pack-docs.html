Formato do Pacote / Pack Format

Um pacote de magias (pack) é um único arquivo JSON com dois blocos: um meta (identificação, autor, licença) e uma lista spells. Um pacote é sempre só dados — nunca JavaScript nem código executável de qualquer tipo. Antes de gravar qualquer coisa, o app valida o pacote contra pack.schema.json e sanitiza todo HTML das descrições. Declarar a licença do conteúdo do pacote é responsabilidade de quem publica.

A spell pack is a single JSON file with two blocks: a meta block (identification, author, license) and a spells list. A pack is always data only — never JavaScript or any executable code. Before writing anything, the app validates the pack against pack.schema.json and sanitizes all HTML in the descriptions. Declaring the license of the pack's content is the publisher's responsibility.

Campos do manifesto / Manifest fields

Campo / Field Tipo / Type Obrigatório / Required Descrição / Description
source string sim / yes Identificador único do pacote. A unicidade é comparação exata de string, sensível a maiúsculas/minúsculas, sem normalização Unicode, contra os pacotes já instalados. Um source repetido não é bloqueado nem sobrescrito: o pacote entra com um identificador com sufixo (ex.: meu-homebrew vira meu-homebrew-2) e a mensagem de sucesso informa qual identificador foi aplicado. / Uniqueness is exact, case-sensitive string comparison, no Unicode normalization. A duplicate source is neither blocked nor overwritten — it installs under a suffixed identifier, and the success message names it.
name string sim / yes Nome legível do pacote. / Human-readable pack name.
version string sim / yes Versão do pacote, formato livre. / Pack version, free-form string.
author string sim / yes Rótulo livre — pseudônimo aceito. Nem e-mail nem qualquer contato é campo do schema. / Free-form label — a pseudonym is fine. Neither email nor any contact info is a schema field.
lang string (ptbr | en) sim / yes Idioma do conteúdo das magias. / Language of the spell content.
edition string não / no Ex.: "2014", "2024". / e.g. "2014", "2024".
spellCount integer não / no Derivado no import a partir do número de magias — o autor não precisa declarar, e qualquer valor declarado aqui é substituído. / Derived on import from the spell count — declaring it is unnecessary, and any declared value is overwritten.
license.id string sim / yes Identificador SPDX quando existir (ex.: CC-BY-4.0), senão um rótulo (proprietary, unspecified). / SPDX identifier when one exists, otherwise a label.
license.attribution string sim / yes Texto de atribuição VERBATIM exigido pela licença — é este texto que o app exibe. / VERBATIM attribution text required by the license — this is the text the app displays.
license.modifications string não / no Nota genérica de modificação exigida pela CC-BY. / Generic modification note required by CC-BY.
license.url string (uri) não / no URL da licença. / License URL.

Campos da magia / Spell fields

Campo / Field Tipo / Type Obrigatório / Required Descrição / Description
name string sim / yes ID estável da magia DENTRO deste pacote — qualquer string única no pacote, não precisa ser inglês. / Stable id for the spell WITHIN this pack — any unique string in the pack, does not need to be English.
displayName string não / no Nome exibido na UI. / Displayed name.
level integer (0–9) sim / yes Nível da magia. / Spell level.
school string sim / yes Escola de magia. / School of magic.
description string (HTML) sim / yes HTML sanitizado no import. Tags preservadas: p, strong, em, i, b, ul, ol, li, table, thead, tbody, tr, th, td, h5, br, hr. TODOS os atributos HTML são removidos (inclusive border em tabelas) — o estilo vem do CSS do app. / Sanitized HTML on import. Preserved tags listed above. ALL HTML attributes are stripped (including table border) — styling comes from the app's CSS.
upgradeDescription string (HTML) não / no HTML, mesma sanitização de description — mesmas tags preservadas, mesmos atributos removidos. / HTML, same sanitization as description.
statBlock string | null não / no HTML, mesma sanitização de description. / HTML, same sanitization as description.
ritual boolean não / no É rituais? / Can be cast as a ritual?
concentration boolean não / no Exige concentração? / Requires concentration?
castTime string não / no Tempo de conjuração. / Casting time.
castTimeNote string não / no Nota adicional sobre o tempo de conjuração. / Extra note about casting time.
range string não / no Alcance. / Range.
components string não / no Componentes (ex.: V, S, M). / Components.
componentsNote string não / no Nota sobre componentes materiais. / Note about material components.
duration string não / no Duração. / Duration.
source string não / no Livro/fonte da magia (ex.: Player's Handbook) — não confundir com meta.source. / Spell's source book — do not confuse with meta.source.
class array de string não / no Classes que podem conjurar a magia. / Classes that can cast the spell.
classNote array de string não / no Notas por classe. / Per-class notes.
url string não / no Link de referência externa. / External reference link.

Limites e rejeições / Limits and rejections

  • Teto de 10 MB (10485760 bytes) por pacote, medido em bytes do arquivo. / 10 MB cap (10485760 bytes) per pack, measured in file bytes.
  • JSON malformado. / Malformed JSON.
  • Pacote que não bate com pack.schema.json. / Pack that does not match pack.schema.json.
  • Chaves __proto__, constructor e prototype em qualquer nível. / __proto__, constructor and prototype keys at any level.

Todas essas rejeições acontecem antes de qualquer gravação em storage. / All of these are rejected before any write to storage.

Importar por URL / Import from URL

Só funcionam hosts que servem o arquivo com cabeçalho CORS permissivo: raw.githubusercontent.com, Gist (gist.githubusercontent.com) e jsDelivr (cdn.jsdelivr.net). Em qualquer outro host, baixe o arquivo e importe por upload.
Only hosts that serve the file with a permissive CORS header work: raw.githubusercontent.com, Gist (gist.githubusercontent.com) and jsDelivr (cdn.jsdelivr.net). On any other host, download the file and import it via upload instead.

Schema completo: pack.schema.json — pode ser apontado direto num validador JSON Schema online.
Full schema: pack.schema.json — point an online JSON Schema validator directly at it.
